## Requirements
- All inputs should be treated as lowercase. The system should be case-insensitive.
- The suggestions should be ranked by alphabetically and also by frequency of use.
- Default limit to 10 suggestions, but allow the user to specify a different limit if desired.
- The frequency should be incremented each time a word is inserted into the system.
- Words can be added dynamically during runtime.
- Skip update or delete functionality for now.
